Sistema local en Python diseñado para automatizar el descubrimiento, extracción, transcripción, análisis de IA y generación de variaciones de guiones de los videos más virales (outliers) de cuentas de Instagram de la competencia (ej. @cuenta_de_ejemplo).2. Flujo de Trabajo del Sistema (Pipeline)Extracción y Filtrado (Scraper): Conexión vía Apify o Instaloader para extraer metadatos de los últimos $N$ posts de la cuenta objetivo.Detección de Outliers: El sistema calcula la mediana histórica de visualizaciones de la cuenta. Un video se cataloga como "Viral/Outlier" si sus vistas superan un multiplicador configurado (ej. $\ge 3\times$ la mediana).Descarga Multimedia: Descarga el archivo de audio (.mp3) de los Reels detectados como virales.Transcripción (STT): Envío del audio al motor local OpenAI Whisper para obtener la transcripción exacta de las palabras habladas.Razonamiento Cognitivo (LLM): Envío del guion transcrito y metadatos a un LLM (vía API o modelo local) para realizar:Clasificación del Gancho (Hook Strategy).Análisis psicológico de retención.Generación automática de un guion adaptado.Persistencia y Alerta: Almacenamiento de toda la inteligencia procesada en la base de datos y envío de un resumen opcional vía Telegram.3. Requisitos Funcionales y No FuncionalesModularidad: Cada etapa (Scraping $\to$ Transcripción $\to$ Análisis IA) debe ser independiente para evitar cuellos de botella si falla una API externa.Control de Errores y Rate Limits: Manejo estricto de reintentos con pausas exponenciales para evitar bloqueos por parte de Instagram.Costos y Eficiencia: Procesar únicamente los videos que cruzan el umbral de viralidad, evitando gastar recursos o tokens de IA en contenido irrelevante.
